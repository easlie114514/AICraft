# 基本呼叫场景示例

本示例展示如何使用SIPP进行基本的呼叫测试。

## 场景描述
模拟主叫方（UAC）呼叫被叫方（UAS），完成INVITE-100 Trying-180 Ringing-200 OK-ACK-BYE的完整呼叫流程。

## 文件说明
- `uac.xml`：主叫方脚本，主动发起呼叫（使用[field0]和[field1]参数）
- `uas.xml`：被叫方脚本，响应呼叫请求

## 运行步骤

### 1. 启动被叫方（UAS）
```bash
sipp -sf uas.xml -p 5060
```

参数说明：
- `-sf uas.xml`：指定脚本文件
- `-p 5060`：监听端口

### 2. 启动主叫方（UAC）- 方式一：使用-inf文件（推荐）
```bash
# 创建caller_callee.csv文件
cat > caller_callee.csv << EOF
1000;2000
1001;2002
1003;2004
EOF

# 运行UAC，从文件读取主被叫号码
sipp -sf uac.xml -inf caller_callee.csv 192.168.1.100 -p 5061 -d 10000 -i 192.168.1.101 -mp 6000
```

参数说明：
- `-sf uac.xml`：指定脚本文件
- `-inf caller_callee.csv`：从文件读取主被叫号码
  - 第一列对应[field0]（主叫方）
  - 第二列对应[field1]（被叫方）
- `192.168.1.100`：SIP服务器IP（对应[remote_ip]）
- `-p 5061`：本地SIP端口（对应[local_port]）
- `-d 10000`：通话时长10秒（对应pause的milliseconds）
- `-i 192.168.1.101`：本地IP地址（对应[local_ip]和[media_ip]）
- `-mp 6000`：媒体端口（对应[media_port]）

### 3. 启动主叫方（UAC）- 方式二：使用命令行参数
```bash
sipp -sf uac.xml -s 2000 192.168.1.100 -p 5061 -d 10000 -i 192.168.1.101 -mp 6000 -s 1000
```

参数说明：
- `-s 2000`：被叫方号码（对应[field1]）
- `-s 1000`：主叫方号码（对应[field0]）

### 4. 完整示例（使用-inf文件）
假设环境配置：
- SIP服务器：192.168.1.100
- 主叫方：192.168.1.101
- 被叫方：192.168.1.102

**步骤1：创建主被叫号码文件**
```bash
cat > caller_callee.csv << EOF
1000;2000
1001;2001
1002;2002
EOF
```

**步骤2：启动被叫方（在192.168.1.102上）**
```bash
sipp -sf uas.xml -p 5060 -i 192.168.1.102 -mp 8000
```

**步骤3：启动主叫方（在192.168.1.101上）**
```bash
sipp -sf uac.xml -inf caller_callee.csv 192.168.1.102 -p 5061 -d 10000 -i 192.168.1.101 -mp 6000
```

## 预期结果
1. UAC发送INVITE到UAS（主叫：1000，被叫：2000）
2. UAS发送100 Trying
3. UAS发送180 Ringing
4. UAS发送200 OK
5. UAC发送ACK确认
6. 保持通话10秒
7. UAC发送BYE结束呼叫
8. UAS返回200 OK确认
9. 第二个呼叫自动开始（主叫：1001，被叫：2001）
10. 第三个呼叫自动开始（主叫：1002，被叫：2002）

**步骤3：启动主叫方（在192.168.1.101上）**
```bash
sipp -sf uac.xml -inf caller_callee.csv 192.168.1.102 -p 5061 -d 10000 -i 192.168.1.101 -mp 6000
```

**启动被叫方（在192.168.1.102上）：**
```bash
sipp -sf uas.xml -p 5060 -i 192.168.1.102 -mp 8000
```

**启动主叫方（在192.168.1.101上）：**
```bash
sipp -sf uac.xml -s 2000 192.168.1.102 -p 5061 -d 10000 -i 192.168.1.101 -mp 6000 -s 1000
```

## 压力测试示例

### 高并发呼叫
```bash
sipp -sf uac.xml -s 2000 192.168.1.102 -p 5061 -d 10000 -i 192.168.1.101 -mp 6000 -s 1000 -r 10 -l 100 -m 1000
```

参数说明：
- `-r 10`：每秒发起10个呼叫
- `-l 100`：最大并发100个呼叫
- `-m 1000`：总共发起1000个呼叫

## 常见问题

### 1. 媒体端口冲突
确保UAC和UAS使用不同的媒体端口，避免冲突。

### 2. 防火墙设置
确保SIP端口（5060）和媒体端口（6000/8000）的UDP流量允许通过。

### 3. 网络可达性
确保UAC和UAS能够互相访问，IP地址配置正确。

## 扩展场景
- 修改通话时长：调整pause的milliseconds值
- 修改编解码：调整SDP中的media描述
- 添加认证：使用auth-call模板
- 注册测试：使用register模板
