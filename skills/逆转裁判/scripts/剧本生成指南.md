# 剧本生成指南

## 一、案件真相生成模板

### 基本结构
```
[时间] + [地点] + [凶手] + [作案手法] + [受害者] + [逃走方式] + [遗留证据]
```

### 示例
- **雨夜别墅杀人事件**：
  - 时间：2026年7月5日晚上10点
  - 地点：山田别墅的客厅
  - 凶手：证人A（佐藤花子）
  - 受害者：山田太郎（委托人/被告）的合伙人
  - 作案手法：用客厅的青铜雕像击打受害者头部
  - 逃走方式：从后窗翻出，沿着花园小路离开
  - 遗留证据：后窗上的指纹、花园里的脚印、雕像上的血迹

### 案件伪造逻辑
从真相出发，设计证物链，将结果导向"委托人是凶手"：
1. 伪造动机：委托人与受害者有经济纠纷
2. 伪造证据：在委托人房间发现"凶器"（实际是伪造的）
3. 伪造证言：证人A声称看到委托人在案发时间出现在现场

## 二、角色生成

### 固定角色
- 绫里真宵：直接使用固定模板
- 审判长：直接使用固定模板
- 御剑怜侍：直接使用固定模板

### 随机角色模板

#### 证人（1-2个，根据难度）
```markdown
# 证人 - [姓名]

## 基本信息
- 姓名：[随机生成，如"佐藤花子"、"铃木次郎"]
- 年龄：[30-60岁]
- 职业：[随机，如"邻居"、"秘书"、"商人"]
- 与案件关系：[目击者/知情者/帮凶]

## 性格特点
从以下随机选择2-3个：
- 紧张到结巴，说话时经常停顿
- 过度热情，恨不得把所有事情都告诉警察
- 神神叨叨，总是提到"不祥的预感"
- 自恋，认为自己是最重要的角色
- 健忘，经常说"我记不太清了..."
- 多疑，怀疑所有人
- 话痨，说话总是跑题
- 胆小，一被追问就害怕

## 说话方式
- 根据性格特点设计口癖
- 例如紧张型："那、那天晚上...我、我看到了..."
- 例如自恋型："像我这样重要的人物，当然会注意到..."

## 证言缺陷
- 证言中必须包含1-2个与证物矛盾的点
- 例如：声称看到被告左手持刀，但证物显示被告是右撇子
```

#### 委托人（被告）
```markdown
# 委托人 - [姓名]

## 基本信息
- 姓名：[随机生成]
- 年龄：[25-50岁]
- 职业：[随机]
- 与受害者关系：[合伙人/朋友/亲属]

## 性格特点
从以下随机选择2个：
- 老实巴交，容易被吓到
- 脾气暴躁，一被质疑就发火
- 沉默寡言，不愿意多说
- 过度解释，越描越黑

## 案件背景
- 为什么被指控：[伪造的动机和证据]
- 真实情况：[无辜，但有说不清的不在场证明]
```

#### 关键人（困难模式，第2庭公开）
```markdown
# 关键人 - [姓名]

## 基本信息
- 姓名：[随机生成]
- 身份：[真凶的同伙/知情者/真正的目击者]
- 公开方式：[新证人上台 / 新证物指向]

## 作用
- 提供关键信息，帮助玩家锁定真凶
- 或者本身就是真凶的帮凶，需要玩家识破
```

## 三、证物生成

### 证物类型
1. **物证**：凶器、指纹、脚印、血迹、遗留物品
2. **文书**：信件、日记、合同、照片（用xlsx表格展示）
3. **证言**：证人证词（带缺陷）

### 证物格式
```markdown
# 证物 - [名称]

## 基本信息
- 发现地点：[地点]
- 发现时间：[时间]
- 描述：[详细描述]

## 关键信息
- 这个证物指向：[真相的哪个部分]
- 与哪个证言矛盾：[具体矛盾点]

## 内容
[详细的证物描述，纯文字]
```

### 证物示例
```markdown
# 证物 - 带血的青铜雕像

## 基本信息
- 发现地点：别墅客厅
- 发现时间：案发后1小时
- 描述：客厅茶几上的青铜雕像，底部有血迹和指纹

## 关键信息
- 这个证物指向：凶器是青铜雕像，不是刀
- 与哪个证言矛盾：证人A声称看到被告用刀，但实际凶器是雕像

## 内容
这是一座高约30厘米的青铜雕像，造型是一个持剑的武士。雕像底部有明显的血迹，经检测与受害者的DNA匹配。雕像侧面有一枚清晰的指纹，经比对与证人A（佐藤花子）的指纹吻合。

奇怪的是，委托人山田太郎的指纹并没有出现在雕像上。
```

## 四、证言生成

### 证言结构
每段证言包含3-5句话，其中1-2句包含缺陷

### 证言示例
```markdown
# 证言1 - 案发时间

## 证人：佐藤花子
## 庭次：第1庭

## 证言内容
1. "那、那天晚上10点左右，我在自己家里看电视..."
2. "突然听到隔壁山田别墅传来一声尖叫！"
3. "我跑到窗边一看，看到山田太郎（被告）从别墅后门跑出来！"
4. "他、他手上还拿着刀！满身是血！"
5. "然后他就沿着花园小路逃走了..."

## 缺陷分析
- 第3句缺陷：证人声称从窗边看到被告，但实际证人家的窗户朝向与前门，不可能看到后门
- 第4句缺陷：证人声称被告"拿着刀"，但实际凶器是青铜雕像，不是刀

## 询问触发
- 询问第3句："你说你从窗边看到被告从后门跑出来，但你家的窗户不是朝向前面吗？"
  → 证人慌乱："啊...那、那我可能是记错了..."
  
- 询问第4句："你说被告拿着刀，但现场发现的凶器是青铜雕像，不是刀。"
  → 证人慌乱："那、那个...我可能看错了..."
```

## 五、难度分级证物分配

### 简单（1庭）
- 所有证物在第1庭前全部释放到 workspace/
- 证人1个
- 证言2-3段

### 普通（2庭）
- 第1庭：基础证物（3-4件）+ 证人1
- 第2庭：新证物（2-3件）+ 证人2 或 证人1的补充证言
- 证言总数4-5段

### 困难（3庭）
- 第1庭：基础证物（2-3件）+ 证人1
- 第2庭：新证物（2-3件）+ 关键人公开 + 证人2
- 第3庭：最终证物（1-2件）+ 证人3 或 最终证言
- 证言总数6-8段

## 六、剧本生成流程

1. 确定案件标题
2. 生成案件真相（时间+地点+凶手+手法+受害者+逃走+证据）
3. 设计案件伪造逻辑（如何嫁祸给委托人）
4. 生成角色：
   - 固定角色（真宵、审判长、御剑）
   - 随机证人（1-3个，根据难度）
   - 随机委托人（1个）
   - 关键人（困难模式，1个）
5. 生成证物：
   - 根据真相生成真实证物
   - 根据伪造逻辑生成嫁祸证物
   - 按庭次分配证物
6. 生成证言：
   - 每个证人2-3段证言
   - 每段证言包含1-2个缺陷
7. 计算证物 hash，保存到 case_info.json
8. 创建角色文件
9. 初始化 game_state.json
