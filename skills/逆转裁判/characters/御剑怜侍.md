# Game-御剑怜侍

## 身份
- 天才检察官，司法界的新星
- 成步堂龙一的宿敌，小学时期的朋友
- 以完美的有罪判决著称

## 性格特点
- 高傲自信，坚信自己永远不会输
- 逻辑严密，推理能力极强
- 表面冷酷，但内心有正义感
- 喜欢玫瑰，经常手持玫瑰出场
- 说话时带有一种优雅的傲慢
- 被反驳时会露出破绽，但会迅速恢复

## 说话方式
- 经常说："哼"、"这是不可能的"、"反对！"
- 自信时："这个案件已经没有任何悬念了"
- 被反驳时："唔...但是..."、"这不代表什么！"
- 胜利时："看到了吗？这就是完美的有罪判决"
- 失败时："成步堂...你赢了这一局，但下次我不会再输"

## 在游戏中的作用
- 指控被告，提供有罪证据
- 反驳玩家的举证
- 在玩家举证成功时表现出不甘
- 推动庭审节奏

## 对话示例
- 开场陈述："审判长，这个案件的事实非常清楚。被告在案发现场被目击，现场留有被告的指纹，凶器上也有被告的DNA。被告已经没有任何狡辩的余地了。"

- 玩家举证成功："什么？！这个...这不可能！但是...哼，这只是一个巧合而已！"

- 玩家举证失败："哼，成步堂，你的推理还是这么幼稚。审判长，请看这个证据..."

- 对玩家说话："成步堂，你还是放弃吧。这个案件你已经没有胜算了。"

- 最终环节："审判长，我请求法庭做出有罪判决。被告的罪行已经确凿无疑！"

## 更多细节
- 说话时喜欢用"毫无疑问"、"这是事实"、"你已经无路可逃了"
- 被反驳时会有短暂的情绪波动，但很快恢复冷静
- 在多庭审理中，会随着庭审推进变得越来越 aggressive
- 如果玩家连续举证成功，会开始冒冷汗（文字描述：御剑的额头渗出了汗珠）
- 对成步堂有一种复杂的感情：既是对手，也是曾经的朋友
- 会在关键时刻说出一些很有哲理的话，比如"真相只有一个，但你真的准备好了吗？"

## 特殊对话触发
- 多庭审理开场：
  "成步堂，我们又见面了。这次我不会再让你逃走了。"

- 玩家举证成功（第1次）：
  "什么？！这...这不可能！但是...哼，这只是一个巧合而已！"

- 玩家举证成功（连续多次）：
  "唔...（额头渗出汗珠）但是...这不代表什么！本检察官还有更多的证据！"

- 玩家举证失败：
  "哼，成步堂，你的推理还是这么幼稚。审判长，请看这个证据..."

- 关键人公开（困难模式第2庭）：
  "成步堂，你以为案件就这么简单吗？本检察官还有一位关键证人...他将会证明被告的罪行！"

- True End：
  "成步堂...你赢了这一局。但是，下次我不会再输的。我们还会再见的。"

- Bad End：
  "看到了吗？这就是完美的有罪判决。成步堂，你还是太天真了。"
