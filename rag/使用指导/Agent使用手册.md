# AICraft 使用手册

## 什么是 AICraft

AICraft 是一个 Windows 桌面 AI 能力启动器。像游戏启动器管理 mod 一样，AICraft 用可视化界面管理大语言模型的 Skill、MCP、RAG、记忆等能力模块，让 AI 从聊天工具变成真正的生产力搭档。

**核心特点**：所有数据（对话、配置、记忆）均存储在本地，不上传任何第三方服务器（除你选择的模型 API 之外）。

---

## 快速上手

### 1. 启动应用

- **打包版**：双击 `AICraft.exe`
- **开发版**：运行 `python run.py`

应用会自动启动后端服务（端口 8765）并打开桌面窗口。如端口被占用，会自动等待重试。

> **系统要求**：Windows 10+，Python 3.10+（开发版），Node.js（可选，预置 MCP 需要）。

### 2. 配置模型

第一次使用需要配置模型 API：

1. 点击底部「模型」标签
2. 选择以下方式之一：
   - **DeepSeek 一键接入（推荐）**：填入 API Key，自动创建 Pro + Flash 两个模型配置
   - **自定义模型**：手动填写以下信息

自定义模型需要填写的字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| **名称** | 给模型取个名字 | "DeepSeek Pro" |
| **Provider** | 模型提供商 | deepseek / openai / anthropic / other |
| **Model ID** | 格式 `提供商/模型名` | `deepseek/deepseek-chat` |
| **API Key** | 对应平台的密钥 | `sk-...` |
| **API Base**（可选） | 自定义接口地址 | `https://api.deepseek.com/v1` |

> **关于 tier（Pro/Flash）**：第一个添加的模型会自动设为默认。如果你配置多个模型并分别标记为 Pro/Flash，Auto 路由可以根据问题复杂度自动选择合适的模型。详见「Auto 智能路由」小节。

第一个模型会自动设为默认模型。之后可以在模型页测试连接、切换默认。

### 3. 选择角色

在对话页输入框右侧的角色下拉框中选择预设角色。角色决定了 AI 的说话风格和专业领域。

> **自定义角色**：在 `roles/` 目录下创建 `.md` 文件（如 `代码审查员.md`），文件内容即为角色的 System Prompt。应用会自动识别。

### 4. 开始对话

在输入框输入消息，按 Enter 发送（Shift+Enter 换行）。对话页输入框上方有三个开关：

| 开关 | 作用 |
|------|------|
| **RAG检索** | 开启后 AI 会从你的知识库检索相关文档辅助回答 |
| **记忆注入** | 开启后 AI 会参考历史对话记忆（默认开启） |
| **深度思考** | 开启后 AI 会先进行深度推理再回答（需模型支持） |

## 核心功能

### 多模型自由切换

在输入框右侧的模型下拉框切换模型，支持：

- **手动切换**：直接选择某个已配置的模型
- **Auto（智能路由）**：AI 根据问题复杂度和开关状态自动选择 Pro 或 Flash 模型。路由规则如下（按优先级从高到低）：

| 优先级 | 条件 | 结果 |
|--------|------|------|
| 1 | 开启深度思考 | → Pro |
| 2 | 消息涉及工具操作意图（文件/命令/代码） | → Pro |
| 3 | 开启 RAG 检索 | → Pro |
| 4 | 消息包含复杂关键词（分析/设计/优化/代码等） | → Pro |
| 5 | 消息超过 300 字 | → Pro |
| 6 | 包含代码块 | → Pro |
| 7 | 包含多个问题 | → Pro |
| 8 | 以上均不满足 | → Flash |

> **核心理念**：Pro 兜底，Flash 只在明确简单时才用。宁可多花一点，不要答错。

### 多角色快切

切换角色时，AICraft 会清空当前上下文，注入新角色的 System Prompt。注意：切换角色后 AI 不会保留旧角色的对话语境，"新场景"按钮可以归档当前对话再开始。

### 深度思考

开启深度思考后，AI 会在回答前进行推理分析，推理过程以折叠形式展示。适用于：

- 复杂问题拆解
- 逻辑推理
- 多步决策
- 数学/编程问题

> 深度思考仅 DeepSeek/Claude 模型支持（通过 Anthropic 协议端点）。

### 联网搜索

联网搜索通过模型平台的**原生 server-side 搜索**实现（DeepSeek/Claude/OpenAI 原生支持），AI 在需要时会自动调用，无需手动触发。搜索结果由模型直接整合到回答中。

另外内置了 **4 个快捷数据源**，AI 可通过 function calling 直接查询：

| 工具 | 数据来源 | 用途 |
|------|---------|------|
| `quick_weather` | wttr.in | 实时天气和预报 |
| `quick_gold_price` | 东方财富 | 实时金价（AU9999/黄金T+D/国际现货） |
| `quick_exchange_rate` | 中国银行 | 外汇牌价 |
| `quick_hot_news` | 百度热搜 | 实时热搜榜 |

> 快捷数据源通过免费公开 API 获取，无需额外配置。

### Skill 管理

Skill 是纯文本提示词模块，改变 AI 的回答方式和风格。

1. 点击底部「Skill」标签
2. 设置 Skill 根目录路径（默认为 `skills/`）
3. 每个子目录下的 `SKILL.md` 文件即为一个 Skill
4. 用开关启用/禁用 Skill

> **重要**：只有 Skill 的**名称和第一段描述**会被注入到 System Prompt 中发送给 AI，完整的 SKILL.md 内容不会被注入。因此描述行要精准概括 Skill 的能力，详细规则写到 `SKILL.md` 作为参考文档。

### MCP 管理

MCP（Model Context Protocol）是工具调用模块，让 AI 真正能执行操作。

1. 点击底部「MCP」标签
2. 添加 MCP 连接（支持 SSE 和 Stdio 两种模式）
3. 启用后 AI 可调用对应工具

**两种连接模式**：

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **Stdio** | 启动本地子进程，通过标准输入输出通信 | 本地命令行工具（长连接） |
| **SSE** | 连接 HTTP 服务器，通过 Server-Sent Events 通信 | 远程服务（短连接） |

出厂预置 2 个 MCP（需要 Node.js 环境）：

| MCP 名称 | 功能 | 依赖 |
|----------|------|------|
| 文件管理 | 读写文件、列目录、搜索文件 | Node.js + `@modelcontextprotocol/server-filesystem` |
| 代码执行 | 执行 Python 代码 | Node.js + `@modelcontextprotocol/server-python` |

#### MCP 权限控制

为了安全，AICraft 对 MCP 工具调用有三层权限控制：

1. **路径策略**：信任路径自动放行，拒绝路径直接拦截，支持 Glob 模式（如 `**/node_modules/**`）
2. **代码执行审批**：执行 Python/Shell 代码始终需要用户确认
3. **自动授权开关**：在 MCP 连接卡片上开启「自动授权」可跳过所有确认（仅限你信任的连接）

权限弹窗会显示 60 秒倒计时，超时自动拒绝。文件操作可选择「始终允许」或「始终拒绝」并自动更新路径策略。

> **权限配置位置**：MCP 页面底部有「文件访问权限」面板，可管理信任/拒绝路径列表。配置文件存储在 `config/permissions.json`。

### RAG 知识库

RAG（检索增强生成）让 AI 基于你的私有文档回答问题。

1. 点击底部「RAG」标签
2. 点击「添加数据源」，填写名称和本地文档目录路径
3. 点击「索引」建立向量索引
4. 对话时开启 RAG检索 开关

支持的文件类型：`txt`、`md`、`py`、`json`、`csv`、`html`、`xml`、`docx`、`pdf`

#### Embedding 配置

RAG 支持三种 Embedding 模式（在 RAG 页面顶部配置）：

| 模式 | 说明 | 特点 |
|------|------|------|
| **auto** | 自动选择：有 API Key 用 API，否则用本地 | 推荐默认 |
| **api** | 硅基流动 API（需免费注册获取 Key） | 1024 维，质量更高，需联网 |
| **local** | 本地 ONNX 模型（all-MiniLM-L6-v2） | 384 维，完全离线，首次需下载 ~80MB |

> 切换 Embedding 模式后需**重新索引**所有数据源，因为向量维度不同无法兼容。

#### 索引机制

- 使用 ChromaDB 做向量存储
- 文档按 500 字符分块，50 字符重叠
- 首次索引本地模式时需下载 Embedding 模型（~80MB）
- 每次点击「索引」全量重建

### 长期记忆

AICraft 的记忆系统三层架构，自动运行：

| 层级 | 说明 |
|------|------|
| **L0 实时记忆** | 对话中产生的关键信息自动记录 |
| **L1 短期压缩** | 对话达到一定长度（默认 20 条消息），自动用 Flash 模型压缩为摘要 |
| **L2 长期合并** | 压缩片段积累到一定数量（默认 8 个），自动合并为长期记忆 |

可在「记忆」页面查看和管理：
- **对话历史**：查看、搜索、删除历史对话
- **记忆巩固**：查看短期压缩片段和长期记忆
- **记忆设置**：调整压缩间隔、注入上限、上下文预算等参数
- **智能检索**：输入关键词在所有记忆中搜索

### 上下文预算

AICraft 自动管理发送给 AI 的上下文窗口：

- **6 级优先级**：角色约束（不可裁剪）> Skill > RAG > 记忆 > 跨会话记忆 > 聊天历史
- 超出模型上下文窗口时，按优先级从低到高裁剪
- 对话页输入区左上角显示当前上下文使用百分比：
  - 🟢 绿色：正常（< 75%）
  - 🟡 黄色：告警（75% ~ 90%）
  - 🔴 红色：紧张（> 90%）

### Token 用量统计

点击对话页输入区右侧的 📊 图标可展开 Token 用量面板，查看：

- 本次会话的输入/输出 Token 消耗
- 各模型的使用量分布
- 缓存命中情况

### 新场景

点击对话页输入区右上角的「新场景」按钮可以重置对话上下文：

- 当前场景自动压缩归档到记忆
- 开始全新的对话上下文
- 历史消息保留在界面上（用分割线分隔）

## 配置说明

### 配置文件位置

| 目录/文件 | 内容 |
|-----------|------|
| `config/app.json` | 应用全局设置（主题、语言、Skill 目录） |
| `config/profiles/default/model.json` | 当前选中的模型、角色、上下文参数 |
| `config/permissions.json` | MCP 文件访问权限策略 |
| `config/rag_config.json` | RAG Embedding 配置 |
| `models/` | 模型配置（每个模型一个 JSON 文件） |

### 上下文参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_history_chars` | 50000 | 聊天历史最大字符数 |
| `memory_compact_enabled` | true | 是否启用记忆压缩 |
| `memory_compact_trigger` | messages | 触发方式：chars / messages / both |
| `memory_compact_interval_msgs` | 20 | 每 N 条消息触发压缩 |
| `memory_compact_interval_chars` | 8000 | 每 N 字符触发压缩 |
| `memory_compact_window` | 40 | 压缩时取最近 N 条消息 |
| `memory_compact_max_tokens` | 800 | 压缩摘要最大 token 数 |
| `memory_merge_threshold` | 8 | N 个压缩片段触发合并 |
| `memory_inject_max_chars` | 4000 | 记忆注入最大字符数 |
| `memory_inject_strategy` | latest | 注入策略：latest（最近优先）/ relevant（RAG 检索） |
| `cross_session_inject_count` | 10 | 跨会话注入消息条数 |
| `context_budget_enabled` | true | 是否启用上下文预算管理 |
| `context_window_override` | 0 | 覆盖上下文窗口大小（0=自动检测） |
| `output_reserve_ratio` | 0.20 | 预留 20% 给模型输出 |
| `budget_alert_threshold` | 0.75 | 预算告警阈值（75% 时显示黄色） |

## 常用操作

- **复制消息**：点击消息下方的「复制」按钮
- **停止生成**：生成中点击红色方块按钮
- **查看思考过程**：点击「思考过程」折叠区域展开
- **查看上下文用量**：查看输入区上方的百分比徽章
- **查看 Token 消耗**：点击输入区 📊 图标
- **搜索记忆**：在记忆页搜索框输入关键词
- **手动合并记忆**：在记忆页「记忆设置」→ 点击「合并现在」
